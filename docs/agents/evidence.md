# Evidência de execução

Registrar feature, tentativa, revisões, base Git, diff, ambiente sem segredos, comando, cwd, tempos, código de saída, log íntegro, casos ignorados, consumo, achados e decisões.

Usar `.harness/scripts/run_gates.py --run` localmente. `.harness/evidence-local/` não é versionada. Configurar retenção e acesso no CI antes de chamar evidência de durável.

Resumo não substitui log íntegro. Evidência antiga não aprova código posterior.
